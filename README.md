# Mario на Java

Простой 2D-платформер, созданный в учебных целях и вдохновленный классической игрой Super Mario Bros.

## Технологии

*   **Язык:** Java 11+
*   **Графическая библиотека:** Java Swing
*   **Система сборки:** Apache Maven

## Как запустить проект

1.  **Клонируйте репозиторий:**
    ```bash
    git clone <URL репозитория>
    ```
2.  **Откройте проект в IntelliJ IDEA:**
    - `File` -> `Open...` и выберите папку с проектом.
    - IDEA автоматически определит `pom.xml` и настроит проект.
3.  **Запустите игру:**
    - Найдите класс `Main` в пакете `ru.resider.mario`.
    - Нажмите на зеленую стрелку рядом с методом `main` и выберите `Run 'Main.main()'`.
